共同网格 n 怎样计算
  1. 把两种组学投到同一 H&E 参考坐标，再按配置中的格宽划分网格。
  2. 在所选区域内，每个格子须同时有通过质控的 ST 观测，以及 TIC 大于零的 MSI 像素的有效覆盖。每个合格的格子在 n 中计一次。目标峰或基因这次未检出时，该格仍可用，数值记零。
  3. 一个格子给出一对数：MSI 先逐像素计算离子 / TIC。已知像素尺寸时，按像素与网格的重叠比例加权。ST 先在格内加总基因 UMI 和总 UMI，再算 ln(1 + 10,000 × 基因 UMI / 总 UMI)。
  4. Spearman 对两列数值各自排序，并列取平均秩，再计算秩相关。Pearson 直接比较两列输入。少于 8 格或任一列恒定时，页面不显示相关系数。
