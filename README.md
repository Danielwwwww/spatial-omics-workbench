# 空间组学工作台

工作台把空间代谢组和空间转录组配准到 H&E 切片。上传数据后，可查看离子和基因表达的位置、所选组织区域的统计、两种组学在共同网格上的空间相关，以及配准质控。

## 网页使用

1. 打开 [空间组学工作台](https://danielwwwww.github.io/spatial-omics-workbench/)。
2. 分别选择 H&E、空间代谢组和空间转录组文件。对于由两个文件组成的格式，在对应的文件选择框中同时选中两项。
3. 选择「配准并生成结果」。首次计算会联网加载 Python 和科学计算组件。配准在浏览器的后台线程中运行，文件和结果留在当前设备。
4. 在结果页切换离子、基因或组织区域。联合散点图的每个点对应一个共同网格，点击相关表的基因可联动表达图和散点图。打开「手绘脑区」修改边界，保存后重算区域统计。

## 输入格式

| 模态 | 文件 |
| --- | --- |
| H&E | JPEG、PNG 或 TIFF。高级设置可提供与原图同尺寸的二值组织掩膜。 |
| 空间代谢组 | 单张二维切片的 imzML 与配套 IBD，支持未压缩外部数组。也可使用含 x、y 和 ion:特征 列的 CSV 或 TSV，建议提供每点实测 TIC。 |
| 空间转录组 | H5AD，需有 obsm["spatial"]、唯一基因名及原始计数层 counts 或原始计数矩阵 X。也接受含 x、y 和 gene:基因名 列的坐标计数表，或配对的 Drop-seq summary 与 DGE 宽表。FASTQ 需先生成空间计数。 |

高级设置可指定离子 m/z、基因、标尺、同名解剖点和参考区域多边形。默认 imzML 提取窗口为目标质量的 ±10 ppm。留空时，从抽样谱中选取最多八个重复出现的高强度峰。m/z 和加合物信息可用于提出候选，结构确认需结合碎片谱和标准品。

## 配准与质控

两种组学先生成信号图与采集支持掩膜，再分别对齐到 H&E。程序以组织轮廓初始化变换，使用仿射估计平移、旋转、缩放和剪切。配置中若有同名解剖点，可用于拟合或留出复核。选点应覆盖组织不同方向，兼顾边缘与内部可辨认结构。点宜分散，留出点独立于拟合。

启用非线性细化时，浏览器会评估受约束的平滑位移场。质控面板显示候选模型的平均和最大留出点 TRE，并标明当前图层采用的模型。离子图、基因图和网格统计都使用所选模型的坐标。H&E 组织轮廓限制统计范围，参考分区可通过配置导入，边界可手绘复核。

本地 Python 服务安装 STalign 后，可再比较 [STalign LDDMM](https://doi.org/10.1038/s41467-023-43915-7)。程序先将组学信号按工作台的线性模型投到 H&E 坐标系，再用局部自相似特征和拟合点估计形变。候选需通过位移上限、Jacobian、往返误差和轮廓重合检查。至少有三个留出点时才根据 TRE 选用形变。默认要求平均误差下降且最差点误差不增加。优先改善最差点时，可在本地网页切换选项，或在配置中设为 `"tre_priority": "max"`。参与选模的点用于本次比较，跨切片精度需另行评估。

| 指标 | 含义 |
| --- | --- |
| Dice | 两个组织掩膜的交集面积除以两者面积之和再乘以 2。输入只覆盖部分组织时，覆盖范围也会影响该指标。 |
| TRE | 变换后的留出检查点到 H&E 同名点的距离。物理标尺可用时以 µm 报告。 |
| 三模态覆盖 | H&E 组织掩膜中，同时受到 MSI 和 ST 采集支持的面积比例。 |
| 离子 / TIC | 每个像素的目标离子强度除以总离子流。若强度表未给 TIC，程序以表中离子列之和代替。 |
| 每万 UMI 基因计数 | 10,000 × 基因 UMI ÷ 总 UMI。区域值先汇总计数再计算比例。表达图使用统一的蓝青色标。 |
| 共同网格 n | 所选范围内，代谢组和转录组同时具备有效观测的网格数。 |
| 相关系数 | Spearman 比较两列的秩。Pearson 比较离子 / TIC 与对数转换后的基因表达。两者均用于探索空间共定位。 |

### 共同网格怎样计算

1. 在 H&E 坐标系中按格宽划分网格，并限制到三模态共同支持的范围。选择组织区域时，先按区域筛选两类观测。
2. 两边都具备有效观测的格子计一次。TIC 大于零的 MSI 像素与通过计数质控的 ST 点参与配对。有效观测中的目标离子或基因未检出时，该值记零。
3. 参考 [SpaMTP 的跨分辨率映射](https://doi.org/10.1038/s41592-026-03140-8)，对每个 MSI 像素取 3 × 3 个等面积采样点，经同一变换投到 H&E。落入网格的采样比例作为该像素的离子 / TIC 权重。imzML 默认按一个扫描步长估计像素宽，表格输入可设 `msi_pixel_pitch_xy`，单位与表的 x、y 相同。缺少尺寸或设置 `area_weighted: false` 时按像素中心分格。脑区离子概览仍按像素中心汇总。
4. ST 在格内先加总基因 UMI 和总 UMI，再算 ln(1 + 每万 UMI 基因计数)。每个共同网格得到一对数，可在散点图和逐格表中核对。少于 8 格或任一列恒定时省略相关系数。相邻网格可能共享空间信息。

面积映射和联合图在 Python 与浏览器中实现。SpaMTP 的原方法以组学采样单位配对，本工作台使用 H&E 共同网格作为统计单位。

## 本地计算

文件较大、浏览器内存不足或需离线运行时，可使用相同配准代码的本地 Python 服务。安装依赖需要联网，随后可离线运行。

```bash
python -m pip install -r requirements.txt
python -m uvicorn server:app --host 127.0.0.1 --port 8765
```

打开 [本地工作台](http://127.0.0.1:8765) 并选择三类文件。命令行入口可通过 python pipeline.py --help 查看。

需要运行 STalign 时，在同一 Python 环境安装已验证的上游版本，然后重启本地服务。命令行使用者可在配置中写入 `"stalign": true`。

```bash
python -m pip install "STalign @ git+https://github.com/JEFworks-Lab/STalign.git@8a84bf1facc5173f7155400867a09c302125904e"
```
